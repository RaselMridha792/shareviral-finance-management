01 Shape

One door in

Everything the internet can reach is one nginx container. Every other process listens only on a private Docker network and publishes no port at all.

Request path · one VPS · Docker Compose

nginx is the only thing exposed. Everything else is reachable only from inside the network, which is why the rate limits live at the edge and cannot be walked around. The green hop is server-rendering: the web container calls the API directly, so that traffic never touches nginx and is never rate limited.

02 Security

What the arithmetic does not cover

Somebody who already knows the password. Every figure above assumes it is still a secret, which is what two-factor is for, and why the five passwords set at install must change.

Before the rate limit existed, forty attempts in a row all reached the API. Measured, not assumed. The account lock never fired on them, because the address they targeted had no account: that is the attack a per-account lock cannot see.

Below the walls
And if the whole box is lost anyway

Backed up off-site every night, byte-checked at both ends, and restored once for real onto a scratch database. Still open: backup credentials the server itself does not hold.

What no wall here stops

A shell on the server. Every secret sits on it, so it is the floor all six walls stand on, and it is being hardened now.

03 Money

One table holds every taka

Four things write money. Four things read it. They all meet in the same table, so there is nowhere for a second version of a figure to live.

Writes and reads · one transactions table

The register equals the bank statement because there is nowhere else for a figure to live. Payroll and tax do not hold money of their own; they create rows here at the moment cash actually moves.

04 Boundary

HR pays the staff and never sees the company

HR runs payroll, so HR sees pay. Everything that would add up to the company's own position is refused by the API, not hidden in a menu.

One role, drawn as the API enforces it

The role changed once, and the design followed it. HR used to be blocked from salaries; when HR took over payroll that stopped making sense, so the boundary moved to the company's own money instead. Compensation still lives in its own table behind its own permission, and an export is handed the projection the screen already got, so a column cannot appear in a download the screen was not allowed to show.

Enforced by the API. A suite signs in as each role and calls every endpoint, asserting the 403s.

08 Survival

A backup nobody has restored is a rumour

The nightly copy goes off the box. The drill pulls it back down from off-site, not from the disk it was made on, and then checks that the money still adds up.

Nightly copy and the restore drill

The drill fetches from Drive rather than from the server's own disk. A copy that only exists next to the original is not off-site.
